# Sistemas-Integrados-Web
Aplicação web desenvolvida com HTML5, CSS3 e JavaScript, integrando cinco sistemas de gerenciamento: Agenda de Contatos, Biblioteca, Controle Financeiro, Catálogo de Filmes e Cadastro de Alunos. Inclui operações CRUD, pesquisa dinâmica, interface reutilizável e armazenamento de dados com LocalStorage.
